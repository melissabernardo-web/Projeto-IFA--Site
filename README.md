# Projeto IFA - Site de Acessibilidade para a Visão

Site institucional/projeto integrador desenvolvido para apresentar informações sobre acessibilidade visual, física, robótica, programação e inteligência artificial. O projeto foi criado como parte de um trabalho escolar e tem como foco promover inclusão, acessibilidade digital e conscientização sobre tecnologias assistivas.

## 📌 Sobre o projeto

Este site foi desenvolvido para divulgar o projeto integrador do Colégio Estadual José Siqueira Rosas, abordando temas como:

- acessibilidade para pessoas com deficiência visual;
- conceitos de física e óptica;
- robótica e automação;
- programação web com HTML, CSS e JavaScript;
- aplicações de inteligência artificial e tecnologias inovadoras.

## 🎯 Objetivo

Apresentar de forma clara e acessível um projeto acadêmico que conecta diferentes áreas do conhecimento e demonstra como a tecnologia pode contribuir para inclusão e autonomia de pessoas com deficiência visual.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Acessibilidade web (alto contraste, aumento/diminuição de fonte, leitura de página)

## ✨ Recursos do site

- menu de navegação com links internos;
- seção de apresentação do projeto;
- área dedicada à física e tecnociência;
- seção sobre robótica;
- apresentação da disciplina de programação;
- recursos de acessibilidade para leitura e navegação;
- layout responsivo e visual limpo.

## ▶️ Como executar

Como o projeto é estático, basta abrir o arquivo `index.html` em um navegador.

Opcionalmente, você pode usar um servidor local simples, como:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```
